## はじめに

DigitalCloneVを立ち上げた際にAPIのキーなどを入力する必要があります。<br>

## 設定

DigitalCloneVの右上の歯車マークをクリックしてください。<br>

![settings](/kiokuya/images/settings/settings_ui.png)

![settings](/kiokuya/images/settings/settings_set.png)

各項目のキーなどを入力してください。<br>

opeai_api:<br>
OpenaAIのAPIキーです。<br>
[OpenAIAPIKeyの取得](../../install/install_openai_apikey/)<br>
上記で取得したキーを入力してください。<br>

openai_model:<br>
OpenAIのファインチューニングで作成したモデル名を入力してください。<br>
サンプル:ft:gpt-4.1-2025-04-14:personal:~

youtube_api:<br>
YoutubeのAPIキーです。<br>
[YoutubeAPIKeyの取得](../../install/install_youtube_apikey/)<br>
上記で取得したキーを入力してください。<br>

上の３つの項目に入力ができたら「保存して終了」ボタンを押して再起動してください。<br>
