## はじめに

DigitalCloneVは最初に初期設定として名前の入力等が必要です。<br>
例えば名前はAIが名前を呼ばれた時に自分のことだと認識するために必要です。<br>

## 初期設定

DigitalCloneVの中に「InitialSettings.exe」というexeがあるので実行してください。<br>

![init](/kiokuya/images/initsetting/init_main.png)

基本設定の項目を入力してください。<br>
名前は本名でなくハンドルネームでよいです。<br>

![init](/kiokuya/images/initsetting/init_sub.png)

詳細設定は基本的には何も触らなくてよいです。<br>
細かい調整がしたい場合や不具合がある時に変更してください。<br>

・embet_dataベクトル化モデル<br>
OpenAIが提供する埋め込みデータ(あなたの経験談など)を数字の列に変換する為のモデルです。<br>
初期設定は「text-embedding-3-small」になっています。<br>

・冒頭プロンプト<br>
OpenAI(いわゆるChatGPT)に最初に渡すシステムプロンプトです。<br>
システムプロンプトは会話AIがどういう挙動をするかに大きく影響するので何度も微調整して落ち着く形を探す必要があります。<br>

・ハイブリッド検索におけるスカラー検索のベクトル検索における混合率(0~1)<br>
会話AIが質問された時に質問の内容を埋め込みデータ(あなたの経験談など)から検索して一番適切な返答をします。<br>
その際に埋め込みデータから検索する方法としてスカラー検索とベクトル検索の２種類の検索方法を使っています。<br>
この２種類の検索結果を踏まえて最終結果を出すものとして２種類をまとめてハイブリッド検索と呼んでいます。<br>
２種類のそれぞれの検索結果からどちらを重視して返答するかの重みづけがここでの混合率になります。<br>
混合率の数字を小さくするほどベクトル検索結果に偏り、大きくするほどスカラー検索結果に偏ります。<br>
<br>
スカラー検索:文字の比較で検索<br>
ベクトル検索:埋め込みデータと質問文を数字列に変換し、それをコサイン類似度で比較<br>

・検索結果がヒットする類似度のしきい値<br>
検索結果の適切な回答かどうかのスコア付けがされており、ある程度のスコアが無いと回答として採用しないようにする為のしきい値です。<br>
0~1の間の少数で入力してください。<br>

・ハイブリッド検索で持ってくる情報の最大数<br>
ハイブリッド検索結果を複数個取得した上で、会話AIに対して「この中から最適な回答を採用して返答してください」と命令しています。<br>
その時に何個の情報をAIに渡すかの値です。<br>
たくさんAIに渡すとそれだけ返答が遅くなるので3~5程度にしておくことをおすすめします。<br>

・AIの回答のばらつき<br>
会話AIに質問した際に同じ質問であれば同じ回答をするという具合の値です。<br>
0にするとほぼ毎回同じ回答が得られ、1にすると回答にばらつきが出ます。<br>
値を大きくすると埋め込みデータに無い内容も本当のことのように回答するので注意が必要です。<br>
0~1の間の少数でお好みで入力してください。<br>

・チャット履歴の保存数<br>
会話履歴を「chat_history.txt」に保存していてその件数を変更できます。<br>
この会話履歴を会話AIが毎回参照して会話の流れを汲んでくれるようになっています。<br>
会話AIが参照するということは量が増えればそれだけ返答が遅くなるので注意が必要です。<br>

・ハイブリッド検索で持ってきた情報の保存数<br>
ハイブリッド検索結果の履歴用の数です。<br>
会話な流れの中で、検索に引っかからないような質問をされた時に返答する為に検索結果も履歴保存しています。<br>
これも上記チャット履歴と同様に会話AIが参照するものなので数の増やしすぎには注意が必要です。<br>

・sbv2通信用ポート<br>
StyleVertBits2と通信する為のポート番号を変更できます。<br>
デフォルトは「5000」ですが、まれにパソコンの他のシステムが5000版を使っている場合があるのでここで変更できます。<br>
